# Fuentes Oficiales para Corpus Legal Colombiano

## 🏛️ Fuentes Primarias Oficiales

### 1. Constitución Política de Colombia (1991)
- **URL Oficial**: https://www.constitucioncolombia.com/
- **Fuente Primaria**: Corte Constitucional
- **Contenido**: Texto completo con reformas acumuladas

### 2. Rama Judicial - Jurisprudencia
- **Corte Constitucional**: https://www.corteconstitucional.gov.co/relatoria/
- **Corte Suprema de Justicia**: https://cortesuprema.gov.co/
- **Consejo de Estado**: https://www.consejodeestado.gov.co/
- **Contenido**: Sentencias, tutelas, autos

### 3. Secretaría del Senado - Leyes
- **URL**: http://www.secretariasenado.gov.co/
- **Contenido**: Todas las leyes vigentes desde 1887
- **Formato**: HTML/PDF descargables

### 4. Diario Oficial
- **URL**: https://www.imprenta.gov.co/diario-oficial
- **Contenido**: Publicaciones oficiales, decretos, resoluciones
- **Fuente**: Imprenta Nacional

### 5. Función Pública - Normativa
- **URL**: https://www.funcionpublica.gov.co/eva/es/gestor-normativo
- **Contenido**: Decretos, resoluciones, circulares
- **Actualización**: Permanente

## 📋 Prioridades para Ingesta Inicial

### Fase 1: Fundamentos (prioritario)
1. Constitución Política 1991 (completa)
2. Código Civil
3. Código de Procedimiento Civil
4. Código Penal
5. Código de Procedimiento Penal

### Fase 2: Jurisprudencia Constitucional
1. Sentencias hito de tutela (últimos 5 años)
2. Sentencias de constitucionalidad C- (últimas 200)
3. Sentencias de unificación SU

### Fase 3: Leyes Principales
1. Ley 100/1993 - Sistema de Seguridad Social
2. Ley 1437/2011 - Código Contencioso Administrativo
3. Ley 1564/2012 - Código General del Proceso
4. Ley 599/2000 - Código Penal
5. Ley 906/2004 - Código de Procedimiento Penal

### Fase 4: Normativa Sectorial
1. Laboral: Código Sustantivo del Trabajo

4. Administrativo: Estatuto Anticorrupción

## ⚠️ Criterios de Inclusión

✅ **INCLUIR**:
- Fuentes oficiales del Estado colombiano (.gov.co)
- Textos completos con metadatos de publicación
- Normativa vigente con fecha de última actualización
- Sentencias con número de radicación verificable

❌ **EXCLUIR**:
- Blogs jurídicos privados
- Resúmenes de terceros
- Contenido sin fuente primaria identificable
- Interpretaciones doctrinarias no oficiales

## 🔍 Validación de Autenticidad

Cada documento debe tener:
1. **Fuente primaria verificable** (URL .gov.co)
2. **Número oficial** (Ley X de YYYY, Sentencia T-XXX/YYYY)
3. **Fecha de publicación** en Diario Oficial o Gaceta
4. **Texto completo** (no resúmenes)
